# analisis-ventas-python

Análisis de ventas con Python usando Pandas y Matplotlib.  
Incluye un dataset CSV real, cálculos de ingresos, agrupaciones por mes y producto, y visualizaciones profesionales.

## Contenido del proyecto

- **analisis_ventas.py**: Script principal con el análisis.
- **ventas.csv**: Dataset de ventas.
- **Visualizaciones**: Gráficas generadas con Matplotlib (ventas por mes, ingresos totales, productos más vendidos).

## Tecnologías usadas

- Python 3
- Pandas
- Matplotlib

## Funcionalidades

- Lectura y limpieza del dataset CSV  
- Cálculo de ingresos totales  
- Agrupación de ventas por mes  
- Top productos más vendidos  
- Gráficas de barras y líneas
